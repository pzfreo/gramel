# RFQ: CNC Machining of Brass Violin Purfling Cutter

Customer: Paul Fremantle
Email: paul@fremantle.org
Date: 20 May 2026

## Overview

I am seeking quotations for CNC machining of a small precision hand tool used by violin makers.

Each set consists of:

- Five machined brass parts
- One mild steel push rod (cut to length only)

Please quote for the following quantities:

- 1 set
- 20 sets
- 50 sets

The tool is assembled from the supplied parts; an assembly drawing and individual part drawings are included.

---

## Materials

- Brass parts: Free-machining brass (CZ121 / C36000 or equivalent)
- Push rod: Ø4.5 mm bright drawn mild steel, cut to 45 mm long

---

## Parts Included in Each Set

| Drawing | Description |
|--------|--------|
| GRM-01 | Shank |
| GRM-02 | Shaft |
| GRM-03 | Thumbwheel with integral drive screw |
| GRM-04 | Drive plate |
| GRM-05 | Depth-lock bolt with knurled knob |
| — | Ø4.5 × 45 mm steel push rod |

---

## Critical Requirements

- Shaft and shank bore to provide a smooth sliding fit (nominal Ø8 H7/g6)
- All threads to drawing
- Knurled features on GRM-03 and GRM-05
- Parts fully deburred
- Visible brass surfaces finished to a clean satin appearance
- Trial assembly to confirm fit of mating components
